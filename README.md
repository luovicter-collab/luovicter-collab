## 关于我

我是 **Victor**（[@luovicter-collab](https://github.com/luovicter-collab)），独立开发者，2025 年开始在 GitHub 上持续开源。

- 喜欢把 **重复、费时间** 的事做成 **本机可运行** 的小工具，而不是堆在云端或黑盒脚本里  
- 重视 **能看懂界面、能长期维护**：产品感对我来说和代码一样重要  
- 方向偏 **自动化、数据整理、个人效率**；学习研究为主，不接黑产与违规用途  

一句话：**做自己能天天用的开源工具，并把它们打磨到值得给别人用。**
